# Политех для Android

Нативное приложение расписания СПбПУ для Android. Интерфейс и пользовательские функции повторяют версию для iPhone: текущая/следующая пара с таймером, недельный календарь, офлайн-кэш, смена группы, правила посещения, завершение учебного дня, темы, акценты, масштаб и компактные карточки.

## Возможности

- Расписание из публичного API `ruz.spbstu.ru`, без входа и паролей.
- Сохранение 4, 6, 8 или 12 недель; сначала показывается кэш, затем выполняется тихое обновление.
- Постоянное системное уведомление — Android-аналог Live Activity — с обратным отсчётом до конца пары.
- Виджет главного экрана с текущей парой.
- Индивидуальные правила для одного занятия или предмета и типа занятия.
- Системная, светлая и тёмная тема; девять акцентных цветов.
- Фоновое обновление через WorkManager.

## Технологии

- Kotlin 2.4.21
- Jetpack Compose + Material 3 (Compose BOM 2026.09.00)
- Android Gradle Plugin 9.4.1 / Gradle 9.6
- Lifecycle 2.10.0 / WorkManager 2.12.0
- Glance 1.2.0
- Kotlin Serialization и Coroutines

Минимальная версия — Android 7.0 (API 24), целевая — Android 17 (API 37).

## Сборка

Откройте каталог в актуальной Android Studio или выполните:

```sh
./gradlew test assembleDebug
```

Debug APK появится в `app/build/outputs/apk/debug/`. Каталоги сборки, локальные настройки IDE и ключи подписи исключены из Git.

## Конфиденциальность

Приложение обращается только к публичному API СПбПУ. Аналитики, рекламы и сторонних SDK нет. Настройки и расписание хранятся локально на устройстве.
