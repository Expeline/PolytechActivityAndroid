# Политех для Android

Удобное расписание СПбПУ без входа в личный кабинет. Приложение показывает текущую и следующую пару, работает без интернета и умеет напоминать о занятии через постоянное уведомление и виджет.

Можно сменить группу, настроить пропуски, выбрать тему и акцентный цвет. Расписание и настройки хранятся только на устройстве — рекламы и аналитики нет.

## Установка

[Скачать последнюю версию APK](https://github.com/Expeline/PolytechActivityAndroid/releases/latest)

Поддерживается Android 7.0 и новее.

## Для разработки

Проект написан на Kotlin и Jetpack Compose. Откройте его в Android Studio или соберите командой:

```sh
./gradlew test assembleDebug
```
