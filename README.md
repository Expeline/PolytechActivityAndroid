# Политех для Android 2.0

Расписание СПбПУ без входа в личный кабинет. Показывает текущую и следующую пару, работает без интернета, напоминает о занятиях постоянным уведомлением и виджетом. Рекламы и аналитики нет.

Версия для iPhone, iPad и Mac, а также сервер лежат в соседнем репозитории: [PolytechActivityApp](https://github.com/Expeline/PolytechActivityApp).

## Установка

[Скачать последнюю версию APK](https://github.com/Expeline/PolytechActivityAndroid/releases/latest). Нужен Android 7.0 или новее.

## Что нового в 2.0

**Задания группы.** Публикуешь домашку — её видят все, кто выбрал ту же группу, и на Android, и на iPhone. Задание привязано к предмету, срок по умолчанию — начало следующей пары по нему. Отметка «сделал» у каждого своя, группа видит только сколько человек справились. Напоминания приходят за день и за три часа до срока. Без сети всё копится на телефоне и отправляется, когда связь появится.

**История изменений.** Приложение само замечает переносы, отмены, новые пары, смену аудитории и преподавателя. На таких парах появляются метки, отменённая пара остаётся на своём месте зачёркнутой, а в карточке занятия видно, что было и что стало. Это работает и без сервера.

**Новый дизайн в духе Material 3 Expressive.** Снизу появилась навигация «Расписание · Задания · Изменения» со счётчиками. Под карточкой текущей пары — три плитки: пары сегодня, ближайшие сроки, новые изменения. В списке видны перерывы и линия «сейчас». Для идущей пары — волнистый индикатор прогресса. Расписание можно обновить, потянув экран вниз. Анимации стали «пружинистыми», кнопки и навигация окрашены в выбранный акцентный цвет.

## Запуск на своём компьютере

Понадобятся **Android Studio** (или JDK 21 и Android SDK) и, если нужны общие задания, сервер из соседнего репозитория.

### 1. Сервер (если нужны задания группы)

Сервер написан на Swift, поэтому поднимается на Mac:

```sh
git clone https://github.com/Expeline/PolytechActivityApp.git
cd PolytechActivityApp
Scripts/server_setup.sh            # PostgreSQL, базы и таблицы
cd Server && swift run PolyServer serve
```

Он будет слушать порт 8080. Подробности — в README того репозитория. Без сервера приложение тоже работает: расписание и история изменений остаются, а задания просто хранятся только на телефоне.

### 2. Приложение

```sh
git clone https://github.com/Expeline/PolytechActivityAndroid.git
cd PolytechActivityAndroid
./gradlew installDebug   # собрать и поставить на подключённый телефон или запущенный эмулятор
```

Или открой папку в Android Studio и нажми **Run**.

### 3. Подключение к серверу

- **Эмулятор** сам знает адрес сервера — `http://10.0.2.2:8080`, так эмулятор видит компьютер, на котором запущен.
- **Телефон** должен быть в той же Wi-Fi-сети, что и компьютер с сервером. Открой **Настройки → Задания и изменения → Сервер группы**, впиши `http://IP-компьютера:8080` (IP на Mac — `ipconfig getifaddr en0`) и нажми «Подключить».
- На Android 17 система спросит разрешение на доступ к устройствам в локальной сети — его нужно дать, иначе приложение не увидит сервер.

Сервер в локальной сети работает по обычному HTTP, поэтому приложение разрешает незашифрованные соединения (`res/xml/network_security_config.xml`). Расписание с сайта университета всегда идёт по HTTPS. Когда сервер переедет на хостинг с HTTPS, это разрешение можно убрать.

### 4. Тесты

```sh
./gradlew testDebugUnitTest
```

Среди тестов есть проверка, что Android считает «отпечаток» изменения расписания так же, как iPhone и сервер. Благодаря этому история изменений с разных устройств сливается без дублей.

## Из чего сделано

Kotlin, Jetpack Compose и Material 3 (1.5, ради компонентов Expressive), kotlinx.serialization, OkHttp для запросов к серверу и WebSocket, WorkManager для фонового обновления и напоминаний, Glance для виджета.

- `data/` — модели, загрузка расписания, сравнение версий (`ScheduleDiff.kt`), задания и синхронизация с сервером (`StudyRepository.kt`).
- `ui/` — экраны.
- `notification/` — уведомление о текущей паре, об изменениях и сроках.
- `work/` — фоновое обновление.

## Релизная сборка

Подпись берётся из переменных окружения, ключ в репозиторий не попадает:

```sh
export POLYTECH_KEYSTORE_PATH=/путь/к/polytech.jks
export POLYTECH_KEYSTORE_PASSWORD=…
export POLYTECH_KEY_PASSWORD=…
./gradlew assembleRelease
```
